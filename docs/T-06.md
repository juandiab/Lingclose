# T-06 — Proyecto Xcode LingoScan + paquete LingoCore

## Comandos
```
xcodegen generate
xcodebuild -project LingoScan.xcodeproj -scheme LingoScan -destination 'platform=iOS Simulator,name=iPhone 17 Pro Max' -derivedDataPath <scratchpad>/t06-dd build test   # Logs/T-06-xcodebuild.log
cd Packages/LingoCore && swift build && swift test                                                                                   # Logs/T-06-lingocore.log
```

## Resultado
- xcodebuild: `BUILD SUCCEEDED` y `TEST SUCCEEDED`; 1 test (`LingoScanTests.lingoCoreVersionIsExposed`, Swift Testing) verde.
- `swift test` en LingoCore (macOS): 1 test (`versionIsSet`) verde.
- Warnings: solo los del paquete RoundWhiteDiscKit (`#ImplicitStrongCapture` en `SensorScanner.swift` y `SensorSession.swift`), no del código de LingoScan. Aviso inocuo de `appintentsmetadataprocessor`.
- No se tomó captura del simulador en esta tarea (queda para la verificación con `build_run_sim`).

## Decisiones
- `SWIFT_VERSION: 6.2` aceptado por Xcode 27.1 (toolchain Swift 6.4); sin cambios.
- Todos los entitlements (NFC, HealthKit, App Group, Keychain group, iCloud) se mantienen en el archivo; con firma automática el build de simulador no los rechaza. La provisión real (NFC, iCloud, HealthKit) se comprobará en dispositivo (T-14).
- `LingoCore` usa `.iOS("26.0")` y `.macOS("15.0")`; SwiftPM informa la plataforma de destino macOS 14.0 en el log de test, sin efecto.
- Cadenas con `String(localized:defaultValue:)` y claves simbólicas; `Localizable.xcstrings` con `es` base y `en`, `extractionState: manual`.
- Pestañas con la API `Tab` de iOS 18+. `SensorView` existe como placeholder pero aún no está en el `TabView` (ARQUITECTURA §1 la trata como pantalla de feature, no pestaña).
- Info.plist propio (`GENERATE_INFOPLIST_FILE: NO`); AppIcon vacío (sin imagen de 1024 px todavía).
- `project.yml` excluye `Info.plist` y `.entitlements` de las fuentes; `.xcodeproj` generado se versiona.
- `LingoScan/Services/.gitkeep` creado para reservar la carpeta.

## Problemas
Ninguno bloqueante. `RoundWhiteDiscKit` ya existía al empezar, así que se enlazó sin quitarlo.
